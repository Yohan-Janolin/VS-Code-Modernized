# Changelog

All notable changes to the VS Code Modernized extension will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [v2.1.2] - 2026-09-17

### Rebuild - Initial v2 release

- Rebuild by Y. Janolin
- New icon size for Activity Bar (which must be positioned to top)
- Removing of the wrong shadow color for icons in Activity Bar
- New icon color for Activity Bar
- Container's shadow removal
- Unified spaces between main sidebard, editor, terminal and secondary sidebar
- Added missing rounded corner
- New line numbers colors
- New hover color for active line in editor
- Removal of background for sidebars' titles
- Sidebars' title centered vertically
- Correction of the hover effect on the files' tabs
